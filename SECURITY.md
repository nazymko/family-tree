# Security

Family Tree keeps family data on the user's own computer, so a flaw that exposes a tree, a file outside the tree folder,
or the optional agent-access server (MCP, local only) matters.

## Reporting

Please report a vulnerability privately through
[GitHub's private vulnerability reporting](https://github.com/nazymko/gene-tree/security/advisories/new), not in a public
issue. Include the version, the system and the steps. Do not attach a real family tree; describe its shape or use the
generated test tree.

You will get an answer within a week. Fixes ship in the next release, or sooner as a patch release.

## Supported versions

Only the latest release gets security fixes.
